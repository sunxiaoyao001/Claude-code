# Sample photos

Test scenes for the pack preview tools (`scripts/render-samples.mjs`, `scripts/ui-preview.mjs`): strip
thumbnails, contact sheets and UI screenshots render these through the real pipeline. Not part of the
mini program package. All four come from the scikit-image data set, re-encoded as JPEG (quality 92).

| File | Subject | License |
| --- | --- | --- |
| `astronaut.jpg` | Eileen Collins, NASA portrait | Public domain (NASA) |
| `coffee.jpg` | Cup of coffee | CC0, photographer Rachel Michetti |
| `chelsea.jpg` | Chelsea the cat | CC0, photographer Stefan van der Walt |
| `rocket.jpg` | Falcon 9 / DSCOVR launch | Public domain (SpaceX) |

Source: <https://github.com/scikit-image/scikit-image> (`_skimage2/data/_fetchers.py` docstrings).
These are placeholders; the §7.3 sample set (portrait / street / night) replaces them before launch.
