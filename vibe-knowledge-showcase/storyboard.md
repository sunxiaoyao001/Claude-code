## 1. 视觉规范（给动画阶段用）

- **底色**：深色终端风 `#0E0F13`，带很淡的网格和噪点
- **主色**：荧光绿 `#7CFFB2`（代码 / 正确）；辅色：珊瑚橙 `#FF7A59`（梗 / 翻车）；文字白 `#F2F2F2`
- **字体**：标题用粗黑体（思源黑体 Heavy），词条英文和代码用等宽字体（JetBrains Mono）
- **每屏版式（固定模板）**：
  - 顶部：编号胶囊 `#03 / 10` 加一条进度条
  - 中部：大词条（中英双写）
  - 下部：“人话”一行，以及一行橙色吐槽小字
- **动效语汇**（全片统一，不超过 5 种）：
  1. 打字机逐字出现，带闪烁光标（词条登场）
  2. 弹簧缩放进场（overshoot 约 1.15）
  3. 代码块向上滚动
  4. 故障 glitch 抖动 0.2s（“翻车”时）
  5. 卡片左滑切换（词条之间转场，0.25s）
- **字幕**：口播字幕全程烧在下方安全区，每屏最多 14 个字
- **声音**：Lo-fi 鼓点 BPM 约 100，切卡卡在鼓点上；键盘声、“叮”、错误提示音三种音效轮换

## 2. 分镜表

时间码为参考值，旁白按每秒约 4.5 字估算。

### S01 · 钩子（0:00–0:04）
- **画面**：黑屏，光标闪两下，然后飞快打出 `> 帮我做个网站`。回车后，一整个网页“哗”地从代码里长出来。
- **屏幕字**：`你说人话，AI 写代码`
- **旁白**：现在写程序，已经不用会写程序了。
- **音效**：键盘声 → 回车“叮” → 一声 whoosh

### S02 · 标题（0:04–0:08）
- **画面**：网页碎成像素，重新拼出大标题，下面 10 个编号小方块一字排开。
- **屏幕字**：`Vibe Coding 黑话大赏` / `听懂这 10 个词，你就入门了`
- **旁白**：但跟 AI 打交道有一套黑话。10 个词，一分钟带你听懂。

### S03 · #01 Vibe Coding 氛围编程（0:08–0:15）
- **画面**：一个人躺在沙发上，头顶冒出对话气泡；旁边屏幕上的代码自己在滚。
- **屏幕字**：`#01 Vibe Coding · 氛围编程`；人话 `动嘴不动手，代码交给 AI`；吐槽 `看不懂？没关系，能跑就行`
- **旁白**：第一个，Vibe Coding，氛围编程。2025 年由 Karpathy 提出，你只管描述想要什么，代码全交给 AI，甚至不用看懂。
- **备注**：屏幕上出现小字角标 `Collins 2025 年度词`

### S04 · #02 Prompt 提示词（0:15–0:21）
- **画面**：同一个需求打两遍。“做个好看的页面”生成了一坨灰；“深色、极简、带动画的个人主页”生成了漂亮页面。左右分屏对比。
- **屏幕字**：`#02 Prompt · 提示词`；人话 `你给 AI 的需求单`；吐槽 `说不清楚，它就乱猜`
- **旁白**：Prompt，提示词，就是你下的需求单。说得越具体，AI 越靠谱。

### S05 · #03 Token（0:21–0:27）
- **画面**：一句话被切成一块块彩色积木，掉进一个计价器，计价器数字狂跳。
- **屏幕字**：`#03 Token`；人话 `AI 读写的最小单位，也是计费单位`；吐槽 `钱包：我先走了`
- **旁白**：Token，AI 读写文字的最小单位，一个汉字大概一到两个。按 token 收钱，聊得越多，花得越多。

### S06 · #04 上下文窗口（0:27–0:33）
- **画面**：一张桌子能摆的便签有限，新便签不停堆上来，最早的那几张从桌边掉下去。
- **屏幕字**：`#04 Context Window · 上下文窗口`；人话 `AI 一次能记住的内容量`；吐槽 `聊太久，它会忘了开头`
- **旁白**：上下文窗口，就是 AI 的短期记忆。聊得太长，前面说过的事它就忘了。

### S07 · #05 幻觉（0:33–0:39）
- **画面**：AI 头像一脸自信地说出一个不存在的函数 `magicFix()`。按下运行，屏幕 glitch，弹出红色报错。
- **屏幕字**：`#05 Hallucination · 幻觉`；人话 `一本正经地胡说八道`；吐槽 `语气越笃定，越要查一查`
- **旁白**：幻觉，AI 一本正经地胡说八道，能编出根本不存在的东西。
- **音效**：错误提示音加 glitch

### S08 · #06 Agent 智能体（0:39–0:46）
- **画面**：从“一问一答”的聊天框，切到一个小机器人自己开终端、改文件、跑测试、打勾，四个步骤自动连播。
- **屏幕字**：`#06 Agent · 智能体`；人话 `不光会说，还会自己动手`；吐槽 `从军师变成了实习生`
- **旁白**：Agent，智能体。它不只是回答你，而是自己拆任务、写代码、跑测试，一路干到底。

### S09 · #07 MCP（0:46–0:52）
- **画面**：AI 在中间，四周是日历、数据库、GitHub、浏览器的图标，每个都通过同一种 USB-C 形状的插头连上去，连上一个亮一个。
- **屏幕字**：`#07 MCP`；人话 `AI 接外部工具的通用插口`；吐槽 `AI 界的 Type-C`
- **旁白**：MCP，给 AI 接工具的统一接口。像 Type-C 一样，插上就能用日历、数据库、浏览器。

### S10 · #08 Skill 技能包（0:52–0:58）
- **画面**：一个文件夹图标 `SKILL.md` 被拖进 AI 的脑袋，头顶跳出 `+1 技能：做PPT`，游戏升级音效。
- **屏幕字**：`#08 Skill · 技能包`；人话 `一份教 AI 做某件事的说明书`；吐槽 `装上就会，比上培训班快`
- **旁白**：Skill，技能包。把做某件事的方法写成说明书交给 AI，它就学会了。

### S11 · #09 一把梭 / Accept All（0:58–1:04）
- **画面**：一个巨大的 `Accept All` 按钮，被一只手连点。代码改动的 diff 像瀑布一样冲下来，最后整屏变红。
- **屏幕字**：`#09 Accept All · 一把梭`；人话 `AI 改了啥，不看，全收`；吐槽 `爽一时，修一周`
- **旁白**：一把梭，AI 改了什么都不看，全部接受。爽是爽，翻车也快。
- **音效**：连点声 → 低沉的“咚”

### S12 · #10 回滚（1:04–1:10）
- **画面**：时间轴倒带，红屏一格一格退回到绿色的“上一个能跑的版本”，出现 `git revert` 字样。
- **屏幕字**：`#10 Rollback · 回滚`；人话 `一键回到上一个能用的版本`；吐槽 `Vibe Coding 的后悔药`
- **旁白**：所以最后一个词最重要：回滚。勤存档、能撤回，才敢放心让 AI 去折腾。

### S13 · 升华（1:10–1:16）
- **画面**：10 个词条小卡片飞回来，拼成一个大大的 `你` 字（或者一个人的剪影）。
- **屏幕字**：`AI 负责写，你负责想清楚要什么`
- **旁白**：说到底，AI 负责写，你负责想清楚要什么、判断好不好。

### S14 · 结尾互动（1:16–1:20）
- **画面**：光标在输入框里闪：`> 下期你想听哪个领域的黑话？_`
- **屏幕字**：`收藏 = 学会` / `评论区点菜`
- **旁白**：收藏起来，下次看到这些词就不慌了。你还想听哪个领域的黑话？评论区告诉我。
