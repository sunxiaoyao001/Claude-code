# 为什么你刷短视频停不下来？—— 大脑的「奖励陷阱」

一部 2 分 48 秒的 Remotion 知识短片：1920×1080 · 30fps · 16:9，无配音，中文字幕。
画面全部由代码程序化生成，没有使用任何图片、视频或音频素材。3D 大脑、虹膜、手机界面、配乐都在本仓库内生成。

```
npm install
npm run dev                      # Remotion Studio：Main 是成片，S01–S14 可逐场预览
npm run render                   # → out/reward-trap.mp4
```

> 在无 GPU 的 Linux / 云容器里渲染 WebGL，需要 SwiftShader（`remotion.config.ts` 已设置 `swangle`）。
> 想用本机已有的 Chromium Headless Shell，可设置 `REMOTION_BROWSER=/path/to/headless_shell`。

## 视觉与技术要点

- **程序化 3D 大脑**（`src/brain/`）：隐式曲面（多个椭球体平滑并集）描出半球外形；在 12 万顶点的网格上跑 Gray–Scott 反应–扩散，“长”出迷宫状的脑回，外侧裂与中央沟作为钉住条件，让周围脑回顺着它们排列。沟回深度烘焙进顶点颜色充当 AO，外加湿润的 clearcoat 与 sheen 材质。`npm run folds` 可重新生成 `public/brain/folds.bin`。
- **CT 扫描转 X 光**：组织材质用 clipping plane 裁切，全息菲涅尔着色器补上另一半，交界处是一道发光扫描线。发光采用“只加颜色不写 alpha”的混合方式，叠在 CSS 背景上是纯光，不会出现黑边。
- **奖励通路**：VTA → 伏隔核 / 前额叶的 Catmull-Rom 曲线，生长管道加上沿路径流动的点精灵粒子；`projectBrainPoint` 把 3D 解剖点投影到屏幕，用来放置 2D 标注。
- **手机系统**（`src/components/phone/`）：钛金属边框、玻璃高光随倾角移动、屏幕光溢出到环境；9 段手工绘制的“短视频”（日落海面、雨夜霓虹、极光、烟花、橘猫、土星、流体倒色、雨窗、广告）；拇指的接触阴影随按压收紧，信息流用拖拽加临界阻尼弹簧吸附。
- **电影感**：全片统一的色彩脚本（夜蓝、屏幕冷光，多巴胺金是唯一的暖色），胶片颗粒、暗角、多层景深（散景、尘埃、前景虚化）、手持呼吸感镜头，以及缩放穿越、柔光闪白、滑动、溶解四种转场。
- **字幕**：`{关键词}` 会渲染为发光的多巴胺金；逐字聚焦入场，底部渐隐遮罩只在有字幕时出现。
- **配乐与音效**（`scripts/gen-audio.ts`）：纯代码合成，带限带锯齿波 pad、FM 钟声、滤波噪声呼啸、次低频冲击、心跳、时钟滴答、老虎机转轮、Shepard 无限上升音（对应“无限下滑”）、Freeverb 混响，最终响度标准化到 -16 LUFS。`npm run audio` 重新生成。

## 事实依据

- 人均每天 151 分钟：中国网络视听节目服务协会《中国网络视听发展研究报告（2024）》，2023 年短视频用户人均单日使用时长。151 × 365 ≈ 55,115 分钟 ≈ 38.3 天。
- 不确定奖励与多巴胺：Fiorillo, Tobler & Schultz, *Science* 299:1898–1902 (2003)。奖励概率为 50%（不确定性最大）时，多巴胺神经元的持续性活动最强。
- “想要”与“喜欢”分离：Berridge & Robinson 的诱因显著性（incentive salience）理论。
- 可变比率强化（老虎机）：B. F. Skinner 的强化程式研究。
- 无限滚动：Aza Raskin 于 2006 年设计，后来他公开表达过后悔。
- 灰度模式减少屏幕时间：Holte & Ferraro (2020), *The Social Science Journal*。
