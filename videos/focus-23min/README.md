# 《23 分钟：一次分心的真实代价》视频制作方案

> 知识类短视频｜**80 秒**｜科技赛博 HUD 风｜抖音竖屏 9:16（1080×1920 · 60fps）
> 全片由代码生成：Canvas 2D 合成画面 + WebGL2 后期着色器 + Web Audio 程序化配乐 / 音效，可在浏览器实时预览，也可无头逐帧导出 MP4。

---

## 0. 快速开始

```bash
cd videos/focus-23min

# ① 浏览器预览（需要本地 http 服务，图片和 WebGL 不能走 file://）
python3 -m http.server 8080        # 或 npx serve .
# 打开 http://localhost:8080 ，空格播放，S 键显示抖音界面遮挡区

# ② 导出成片 MP4（逐帧渲染，不丢帧）
npm i                              # 安装 playwright（或使用全局 playwright）
node render.mjs                    # → out/focus-23min.mp4（1080×1920 60fps）
node render.mjs --scale 0.5 --fps 30   # → out/focus-23min-preview.mp4（快速预览版）
node render.mjs --vo vo.wav        # 混入配音（配乐自动侧链让路）
node render.mjs --stills 0,30.1,39.7   # 导出指定时间点的 PNG，用于检查画面
node render.mjs --gpu --jobs 3         # 有独立显卡时：GPU 渲染 + 3 路并行分段
```

| 文件 | 作用 |
|---|---|
| `index.html` | 预览播放器：播放 / 拖动 / 逐帧 / 场景跳转 / 实时录制 WebM / 导出 WAV / 导出当前帧 PNG |
| `src/config.js` | **所有可调参数**：尺寸、帧率、配色、字体、场景时间线、字幕台词、关键事件时间点 |
| `src/scenes.js` | 11 个场景的动效编排（每个场景一个函数，画面 = f(时间)） |
| `src/draw.js` | 动效图元库：HUD 准星、动态文字、里程表数字、玻璃碎裂、粒子、通知卡片、仪表 |
| `src/post.js` | WebGL2 后期管线：镜头运动、故障、色散、径向 / 方向运动模糊、辉光、扫描线、颗粒 |
| `src/audio.js` | 120 BPM 合成波配乐 + 30 余种音效，离线渲染为 48kHz 立体声 |
| `src/assets.js` | 字体加载、照片加载与统一调色（Gradient Map） |
| `src/engine.js` | 渲染引擎、字幕 / 章节条 / HUD 叠加层、播放器、导出接口 |
| `render.mjs` | 无头 Chromium 逐帧渲染 → ffmpeg 编码 H.264 + AAC |
| `assets/photos/manifest.js` | **真实照片清单**（文件名、画面要求、搜索词、人脸焦点坐标） |
| `tools/build-fonts.mjs` | 修改文字后重新生成子集字体 |
| `tools/fetch-photos.mjs` | 按照片清单从 Pexels / Unsplash 自动下载真实照片 |

## 2. 画面元素设计

### 2.1 真实照片（真人）

全片使用 **12 张真实照片**（另有 1 个可选的研究者肖像位），全部来自 [Google Open Images 数据集](https://storage.googleapis.com/openimages/web/index.html)（原图在 Flickr），授权 **CC BY 2.0**：可以商用和改编，**必须署名**。完整署名见 [`assets/photos/CREDITS.md`](assets/photos/CREDITS.md)，画面底部 HUD 也有一行授权说明。**发布时请把 CREDITS.md 里的署名段落贴到视频简介。**

挑图方法：在 Open Images 约 170 万张照片的人工标注里，用"人脸 + 手机 + 电脑""黑暗 + 手机""人像"等标签组合筛出 1,175 张候选，再逐张人工挑选。人脸框直接取自数据集的人工标注，HUD 追踪框因此能准确钉在脸上。

照片在引擎里统一调色，原图色调不影响风格：

| 片调 | 用途 | 色彩映射 |

| `cyber` 赛博青 | 主片调（钩子 / 现象 / 机制 / 残留 / 互动） | 深紫黑 → 深蓝 → 霓虹青 → 白 |
| `alarm` 警报红 | 代价段落（时间被偷走 / 压力） | 黑 → 暗红 → 红 → 粉白 |

## 3. 音频设计

### 3.1 配乐（程序化合成，无版权风险）

- **风格**：赛博合成波（Synthwave），A 小调，**120 BPM**，四四拍。
- **编制**：正弦底鼓（带瞬态咔哒）、噪声军鼓 / 拍手 / 踩镲 / 镲片；锯齿 + 方波滚动贝斯（带滤波包络）；双振荡器失谐 pad；方波琶音（附点八分延迟）；恢复段锯齿主旋律（带颤音）。
- **混音**：每个底鼓侧链压低 pad 和贝斯（"抽吸"律动）→ 段落低通 → 总线压缩 → 限幅；程序生成的 2.8 秒混响；最后峰值归一化到 −1 dBFS（整体响度约 −14 LUFS，适合短视频平台）。

| 段落 | 和弦 | 编排 |
|---|---|---|
| 0–6 钩子 | Am | 四拍底鼓 + 闷贝斯；5–6s 去掉底鼓，军鼓滚奏蓄力 |
| 6–10 片头 | Am – F | 全编制爆发：底鼓、拍手、16 分踩镲、滚动贝斯、琶音 |
| 10–20 现象 | Am – F – C – G – Am | 中等能量律动 |
| 20–28 爬坡 | Am – F – C – G | 滤波逐渐打开、琶音升八度、军鼓滚奏 |
| 28–30 紧张 | Am | 鼓组停，低通收紧到 320Hz，29.8s 完全静音 |

## 4. 技术实现方案

**技术栈**：HTML5 Canvas 2D（场景合成）+ WebGL2（后期着色器）+ Web Audio API（OfflineAudioContext 程序化合成）+ Playwright（无头逐帧渲染）+ ffmpeg（H.264 / AAC 编码）。不依赖任何前端框架，打开浏览器就能跑。

```
           ┌───────────────── renderFrame(t) ─────────────────┐
config.js  │  2D 画布 1080×1920                                │
 时间线 ──▶│   scenes.js  场景(lt) ── draw.js 图元             │
 字幕       │   engine.js  HUD 外框 / 章节条 / 字幕             │
 事件点     │        │                                          │
           │        ▼ 纹理上传                                 │
           │  post.js  WebGL2                                  │
           │   Pass1 镜头·故障·像素化·色散·运动模糊（全分辨率） │
           │   Pass2 高光提取 → 1/4                            │
           │   Pass3 高斯模糊 1/4 + 1/8（双层辉光）            │
           │   Pass4 辉光叠加·调色·扫描线·暗角·颗粒·闪光       │
           └──────────────────────┬────────────────────────────┘
                                  ▼
      预览：requestAnimationFrame + 音频时钟同步（index.html）
      导出：Playwright 逐帧 toDataURL → ffmpeg image2pipe → H.264
音频：audio.js ── OfflineAudioContext 离线渲染 80s ──▶ WAV ──▶ ffmpeg 合成
```

**关键设计**

1. **画面 = f(时间)**：所有动画都由时间 t 推导，随机数来自整数哈希（固定种子），粒子 / 碎片都是解析式运动，没有逐帧累积的状态。因此可以任意拖动、任意顺序逐帧渲染，结果完全一致。
2. **声画同一份时间表**：`config.js` 里的 `EV` 记录关键事件时间点，`scenes.js` 和 `audio.js` 都读它，改一个时间点，画面和音效一起移动。
3. **后期参数由场景驱动**：每帧生成一份 `P`（zoom / shake / chroma / glitch / pixel / zoomBlur / dirBlur / bloom / flash / tint……），场景按需叠加冲击包络 `U.hit()`，最后交给着色器。
4. **碎裂特效**：先把 30.0s 那一帧（含主角和通知横幅）离屏渲染成纹理，再按抖动网格三角剖分成 208 块，每块按"撞击点距离"延迟启动，带初速度、重力、旋转、3D 翻转（scaleX = cos）和朝镜头的缩放。
5. **抗平台二次压缩**：扫描线用 4px 周期（避免摩尔纹），导出 BT.709 色彩标记，yuv420p。

**二次开发**

| 想改什么 | 改哪里 |
