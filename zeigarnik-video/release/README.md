## 当前版本说明

- 配音：本地开源 TTS（Kokoro v1.1 第 57 号中文女声，Apache-2.0），每句都用中文语音识别回读校对过。
- 配乐和音效：程序合成，没有第三方版权素材。
- 人物镜头：这一版没有写实人物。生成写实人物需要访问 image.pollinations.ai，这次会话的网络策略拦截了它，所以人物镜头暂时用场景空镜和动效代替（地铁车窗、老餐馆、站台、夜街、书桌、天亮的城市）。
- 放行 image.pollinations.ai 后运行下面三条命令，就能生成带写实人物的版本并覆盖这里的文件：

```bash
node render/gen-images.mjs
node render/render.mjs --final
node render/render.mjs --final --cover
```
