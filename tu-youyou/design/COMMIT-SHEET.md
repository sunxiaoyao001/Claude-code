# COMMIT-SHEET — 一握青蒿（屠呦呦）

Register: **direct**（滚动导演的单页电影）。Recon 未跑（无交互式浏览，跳过），反射项依据 taste.md 表格自行推导。

## 1. Peak
第 3 场「一握青蒿」：钉住 400vh 的舞台。190 枚样品编号逐个被划掉 → 葛洪《肘后备急方》原句竖排逐字浮现，“渍”字被朱笔圈出 → 温度数字从 78.3°C（乙醇沸点）滚落到 34.6°C（乙醚沸点），底色由陶土的热色褪成青蒿绿 → 一枚朱红印章「191」盖下。

## 2. Color
- 纸：`oklch(0.962 0.008 145)`，带一点青绿偏色的真·纸白（色相 145，避开 40–100 的米色带）。
- 墨：`oklch(0.23 0.035 155)`，绿黑墨色。
- 青蒿绿：`oklch(0.40 0.075 142)`，**committed**，约占页面 40%（第 2、5 场整屏铺色，第 3 场高潮的终态）。
- 朱印：`oklch(0.53 0.18 28)`，只用在两处：191 印章、分子里的过氧桥。印泥是中国文书的真实惯例，红色只标“起作用的那一下”。
- 背景平均亮度目标 **L ≈ 0.72**（纸 0.96 与青蒿绿 0.40 交替）。场景句：一间白天的标本室，标本台纸上压着一株干燥的黄花蒿。所以是亮的页面。

## 3. Type
- 展示：Noto Serif SC 900/700（宋体的横细竖粗，古籍刻本的血统；竖排古文也用它）。
- 正文：Noto Sans SC 400/500。
- 对比轴：衬线宋体 × 无衬线黑体。不用 Inter：页面是中文，西文字体只会出现在拉丁学名里，交给宋体自带的西文字形。

## 4. Grid break
英雄区的植物线描越出左侧页边、并向下压进第 2 场的绿色幕布；高潮场里竖排古文是一根满高的柱子，直接切开 190 格的样品网格。

## 5. Motion budget（3 族）
1. entrance-reveal：植物线描自绘（载入时）、分子键逐根画出、结尾引文。
2. scroll-scrub：第 2 场逐字“着墨”、第 5 场年表随一根发丝线着墨。
3. pinned-stage：只有第 3 场高潮。
另有一处非滚动的环境动效：植物随指针轻摆。

## 6. Reflex check
- a) 科学家传记页的一阶反射：深色背景 + 大幅黑白肖像 + 圆点时间轴 + “他改变了世界”式口号 + 数据卡片。
- b) 二阶反射：米色纸张 + Playfair 衬线 + 报纸式细线分栏的“编辑风”。
- c) 我们的偏离：标本室与药典。主角是一株植物、一句古文、一个温度、一个分子，不放人像。视觉语言取自植物标本台纸、古籍竖排、实验记录的样品编号和印章。

## 7. House tells broken
1. 近黑背景 → 亮的纸面（L 0.96）与青蒿绿交替，戏剧性来自温度的冷热变化。
2. 字标即英雄（巨大名字居中）→ 英雄区的主体是植物线描和竖排《诗经》句，名字只是中号标题。
3. 状态栏式页眉（logo · 状态点 · 按钮）→ 页面没有任何固定页眉和角标。
4. 等宽小字服务标签 → 全站不用等宽字体，标签用宋体小号。
