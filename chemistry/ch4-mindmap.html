认识化学反应第 4 章
4.1化学反应发生的条件

燃烧

可燃物与氧气发生的一种发光、放热的剧烈的氧化反应。

缓慢氧化：呼吸作用、食物腐烂、铁生锈；缓慢氧化积累热量可引起自燃。

燃烧的条件（三者同时具备）

  • 物质具有可燃性
  • 可燃物与氧气（空气）接触
  • 温度达到可燃物的着火点

实验：铜片上白磷燃烧、红磷不燃烧（着火点不同）；热水中白磷通入氧气后燃烧。

灭火的原理

  • 清除或隔离可燃物：森林开辟隔离带、关闭燃气阀门
  • 隔绝氧气：锅盖盖灭油锅火、沙土覆盖
  • 降温到着火点以下：用水浇灭

着火点是物质的固有属性，一般不能“降低着火点”。

促进燃烧

  • 增大氧气的浓度
  • 增大可燃物与氧气的接触面积（如煤做成蜂窝煤）

氧气不足时不完全燃烧，碳生成有毒的 CO。

爆炸与安全

  • 可燃物在有限空间内急剧燃烧，气体体积迅速膨胀
  • 可燃性气体、粉尘（面粉、煤粉）遇明火可能爆炸
  • 点燃可燃性气体前要先验纯

禁止烟火禁止吸烟当心爆炸

反应条件与反应快慢

常见条件：点燃加热高温通电催化剂

影响反应快慢：温度、反应物浓度、接触面积、催化剂。

催化剂改变反应速率，本身的质量和化学性质在反应前后不变。

4.2化学反应中的质量关系

质量守恒定律

参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和。

只适用于化学变化；守恒的是质量，不是体积；未参加反应的部分不计入。

实验验证

  • 白磷（红磷）在密闭锥形瓶中燃烧，气球缓冲气压
  • 铁钉与硫酸铜溶液反应：Fe + CuSO4  ══ FeSO4 + Cu
  • 碳酸钠与盐酸在敞口容器中反应，天平不平衡：气体逸出

有气体参加或生成的反应，必须在密闭容器中验证。

微观解释

化学反应是原子的重新组合：原子的种类、数目、质量都不变。

“六不变·两改变·两可能变”

  • 宏观不变：物质总质量、元素种类、元素质量
  • 微观不变：原子种类、原子数目、原子质量
  • 一定改变：物质种类、分子种类
  • 可能改变：分子数目、元素化合价

应用

  • 解释现象：蜡烛燃烧后质量变小、镁带燃烧后质量变大
  • 推断物质的元素组成（如某物质燃烧生成 CO2 和 H2O，一定含 C、H，可能含 O）
  • 根据原子守恒确定未知物质的化学式
  • 计算某物质的质量（表格数据题）
4.3化学方程式

定义与书写原则

用化学式表示化学反应的式子。

  • 以客观事实为基础
  • 遵守质量守恒定律（等号两边各原子种类、数目相等）

书写步骤

  • 写：左反应物、右生成物，中间短线
  • 配：配平（最小公倍数法、奇数配偶法、观察法）
  • 注：标明条件，短线改等号
  • 标：生成气体标 ↑，溶液中生成沉淀标 ↓

反应物中有气体（或固体）时，生成的气体（或固体）不标 ↑（↓）。

意义（以氢气燃烧为例）

2H2 + O2 点燃══ 2H2O

  • 质：反应物、生成物和反应条件
  • 量：质量比 4 : 32 : 36 = 1 : 8 : 9
  • 粒子：分子个数比 2 : 1 : 2

常见反应

C + O2 点燃══ CO2 4P + 5O2 点燃══ 2P2O5 3Fe + 2O2 点燃══ Fe3O4 2H2O 通电══ 2H2↑ + O2↑ 2KMnO4 △══ K2MnO4 + MnO2 + O2↑ 2H2O2 MnO2══ 2H2O + O2↑ CH4 + 2O2 点燃══ CO2 + 2H2O

根据化学方程式计算

步骤：设 → 写 → 找 → 列 → 求 → 答

例：加热分解 3.16 g 高锰酸钾，可得氧气多少克？
解：设可得氧气质量为 x
2KMnO4 △══ K2MnO4 + MnO2 + O2↑
316           32
3.16 g          x
316 / 32 = 3.16 g / x，x = 0.32 g
答：可得氧气 0.32 g。

代入的必须是纯净物的质量；单位统一；设未知数不带单位。
