# 科普视频（Remotion）

这个项目里有三个视频：

1. **AI 根本不会“说话”，它只会猜下一个字**：横屏 1920×1080，3 分 45 秒，配口播字幕（下文大部分说明针对它）
2. **囚徒困境**：抖音竖屏 1080×1920，80 秒，纯配乐，见后文[《囚徒困境》](#囚徒困境抖音竖屏)
3. **白熊效应**：抖音竖屏 1080×1920，132 秒，纯配乐，节奏放慢、一屏一句，见文末[《白熊效应》](#白熊效应抖音竖屏)

## 一、AI 根本不会“说话”，它只会猜下一个字

用 [Remotion](https://www.remotion.dev/) 做的科普视频：1920×1080、30fps，总长约 3 分 45 秒，一共 8 个镜头，画面全部由代码生成。

| # | 镜头 | 内容 |
| --- | --- | --- |
| 0 | 开场 | AI 写诗到一半定格，打出“它只会猜下一个字” |
| 1 | 猜字游戏 | 床前明月＿ / 今天天气真＿ 的候选字概率；token 是什么 |
| 2 | 一个字接一个字 | “天空为什么是蓝的”，逐字预测、接到句尾、再猜下一个 |
| 3 | 它是怎么学会的 | 海量文本喂进模型 → 遮字猜 → 拧旋钮 → 几千亿参数 → 助手课 |
| 4 | 猜字凭什么变聪明 | 侦探小说“凶手就是——”，冰山：语法 / 常识 / 推理 |
| 5 | 为什么每次回答不一样 | 按概率抽签的转盘，温度 T 对分布的影响（真实的 softmax 计算） |
| 6 | 一本正经地胡说八道 | 编出来的书名被盖“查无此书”章；联网搜索与自行核实 |
| 7 | 结尾 | 满屏都是猜测，留下问题“算不算真的懂” |

## 常用命令

需要 Node.js 22.18 及以上版本（`scripts/` 里的 .ts 脚本直接用 Node 运行）。

```bash
npm install
npm run dev            # 打开 Remotion Studio 实时预览（Scenes 文件夹里可以单看每个镜头）
npm run render         # 渲染带字幕的成片 → out/ai-video.mp4
npm run render:nosubs  # 渲染无字幕版本 → out/ai-video-nosubs.mp4（适合自己在剪映里加字幕）
npm run render:pd      # 渲染《囚徒困境》→ out/prisoners-dilemma.mp4
npm run render:wb      # 渲染《白熊效应》→ out/white-bear.mp4
npm run srt            # 导出 out/subtitles.srt 和录音稿 out/narration.txt
npm run audio          # 重新生成配乐和音效（改了文案、时间轴变了之后运行）
npm run audio:pd       # 重新生成《囚徒困境》的配乐和新增音效
npm run audio:wb       # 重新生成《白熊效应》的配乐和音效
npm run typecheck
```

## 改文案、对配音

所有口播文案都在 `src/script.ts`，一行就是一句字幕。

- **时长按字数自动算**，默认语速 `CHARS_PER_SECOND = 4.4`（约 260 字/分钟），画面会跟着文案一起移动。
- 句子上的 `cue` 是画面节拍，比如 `{text: '猜错了', cue: 'wrong'}`，镜头里通过 `cues.wrong` 拿到这句开始的帧。改文案时保留 `cue`，画面就不会对不上。

推荐的配音流程：

1. 运行 `npm run srt`，照着 `out/narration.txt` 录音（里面标了每个镜头的开始时间）。
2. 如果录出来整体偏快或偏慢，调整 `CHARS_PER_SECOND`。个别句子对不上，就给那一句加 `sec: 实际秒数`。
3. 把录音放到 `public/voiceover.mp3`，在 `src/Video.tsx` 的配乐那一行下面加
   `<Html5Audio src={staticFile('voiceover.mp3')} />`，并把 `src/Root.tsx` 里的 `musicVolume` 调到 0.3 左右（让配乐给人声让路），然后重新渲染。

   也可以直接把 `render:nosubs` 的成片拖进剪辑软件，在那里配音、加 BGM 和字幕。

## 配乐与音效

全部由 `scripts/make-audio.ts` 用代码合成，不涉及版权：

- **配乐** `public/audio/music.mp3`：96 BPM，C 大调，Fmaj7 → G → Em7 → Am7。按镜头分段编排：
  - 开场：垫音配琶音。定格时收住，揭晓那一下给一个重音。
  - 01～03：加入鼓和贝斯；逐字生成那段换成更密的十六分琶音。
  - 04 侦探：去掉鼓，换成低音持续音加钟声，营造悬疑感。"理解"出现时滤波打开。
  - 05～06：律动回来。
  - 结尾：提问时只留垫音和钟声，最后落在 Cmaj9。
- **音效** `public/audio/sfx/`：打字、弹出、转场、猜错、拧旋钮、计数、转盘、盖章等 18 个。每个镜头用 `<Sfx name=… at={帧} />` 按画面事件触发。

配乐的分段时间读的是 `src/script.ts` 里的时间轴，所以改了文案以后要运行一次 `npm run audio`。成片默认带配乐和音效，Studio 里可以通过 `music` / `sfx` / `musicVolume` 这三个属性单独开关或调音量。

## 囚徒困境（抖音竖屏）

1080×1920 · 80 秒 · 24 fps · 120 BPM，纯配乐，没有配音。风格是**瑞士国际主义平面风格的动态版**（按 [Swiss Motion Graphics 风格规范](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/swiss-motion/STYLE.md)）：

- **先讲一个情景，再讲道理**：开头 12 秒是一个夜里的小故事（探照灯、审讯室、警察的条件），观众先成为"你"，然后灯光铺满纸面，点题"囚徒困境"，审讯室变成一张表。
- **系统**：一张白纸上的 2×2 收益矩阵。行是 A 的选择，列是 B 的选择。**1 个基线单位（24 px）= 1 年刑期**，刑期就是黑块的高度。
- **象形图（火柴人）**：按 Aicher / Isotype 的路子在网格上画的小人和道具：圆头、等粗线条、平涂。A 墨黑，B 浅灰，警察戴警帽。每一句话旁边都有一幅小插图；矩阵里，坐牢的人坐在自己那摞刑期里，刑期为 0 的人在数字"0"的空心里往外走，合作那块橙色上站着两个人。
- **夜**：序幕里的夜是一张墨色遮罩，光是遮罩上挖掉的多边形，光里的东西照常画在纸上。探照灯每拍追一次；一道刀线落下，光柱塌成一条线，留下来就是两间屋子之间的墙。
- **一个信号色**：囚服橙 `#FF5A00`，全片只给"都沉默、各 1 年"那一块，也就是合作。它是唯一不守网格的元素：理性推演用刀切删掉它所在的行和列，它却悬在原处，坐标读数显示 `off grid`。到了重复博弈那段，它线性、不吸附地穿过 16 轮对局，最后回到格子里。
- **两条曲线**：`cubic-bezier(.7,0,.2,1)` 和线性。没有回弹，没有淡入淡出。入场是裁切揭示和擦除，删除是刀切，所有落点都在 120 BPM 的拍子上（1 拍 = 12 帧）。
- **画面和声音共用一份时间数据** `src/pd/score.ts`。每一次落位都是一声干的印刷拟音（铅字、裁纸刀、纸张、数字落位、毛毡、橡皮章）。序幕：追逐是四拍底鼓和十六分锯齿脉冲，被罩住时一切硬停两拍，审讯室里只剩钟的滴答、很轻的根音和八分音符的木琴音型；点题时乐队和主旋律一起进，之后每一条规则加一件乐器；"例外"移动时鼓全部撤掉，只剩一条跟着它位置滑动的正弦音；第 78 秒强拍全部硬停。混音 −14 LUFS。

| 小节 | 秒 | 段落 |
| --- | --- | --- |
| 1 | 0–2 | 序幕。满屏墨色，一道探照灯斜着打下来，两个人在光里跑，光每拍追一次。"凌晨 2 点，你和同伙，被抓了。"——光柱罩住，两人举手，一切静止 |
| 2 | 2–4 | 一道刀线竖着划下，光塌成一条线（灯灭）；夜色收进下半页的纸里。两间黑屋子各亮一盏灯："警察把你们分开审讯。" |
| 3–5 | 4–10 | 警察从暗处走进灯下："揭发他，你就能走。"巨大的 **0 年**（空心里一个人往外走），旁边是他坐 10 年的铁栏。隔壁：他听到的是同一句话 |
| 6 | 10–12 | "你会怎么选？"两个选项，一个框在沉默和揭发之间来回跳；两个人也跟着来回换 |
| 7–8 | 12–16 | 点题：灯光铺满纸面，"囚徒困境"；审讯室被刀切掉，换成坐标轴 |
| 9–13 | 16–26 | 规则一：四格刑期一格一格长出来，每长一级钟琴上行一个音 |
| 14–18 | 26–36 | 规则二：站在 A 的角度，0 < 1、5 < 10，揭发更划算。刀切删掉"A 沉默"那一行，只有橙色留下 |
| 19–22 | 36–44 | 规则三：B 也这么想，删掉一列。几乎无声的一小节，然后推进到"都揭发"那格：各判 5 年。明明都沉默，只要 1 年 |
| 23–24 | 44–48 | 结论：一个用小人写成的等式——个人理性（互相指认，各 5 年）≠ 集体理性（握手，各 1 年） |
| 25–27 | 48–54 | 画面等分三格：价格战 / 内卷 / 军备竞赛，同一套规则 |
| 28–34 | 54–68 | 重复博弈：拉远成一整面 16 轮的墙，橙色线性穿过；第 4 轮被背叛、第 5 轮还击、第 6 轮原谅。阿克塞尔罗德 1980 年对战赛，冠军站上领奖台：一报还一报 |
| 35–40 | 68–80 | 一次性的交易里背叛最理性；但人生是一场重复博弈（两个人并肩往前走）。最后只剩橙色木板上握手的两个人和一个问题 |

## 白熊效应（抖音竖屏）

1080×1920 · 132 秒 · 24 fps · 60 BPM、3/4 拍，纯配乐，没有配音。同样是瑞士国际主义风格的动态版 + 火柴人象形图，但**节奏放慢、讲得更清楚**：一小节 = 3 秒 = 一屏，一屏一句话、不超过 20 字。

选题和结构参考了抖音「Vibe知识大赏」话题下爆款视频的规律：开头 3 秒抛出挑战（"接下来 10 秒，请不要想一只白熊"），片中有一句明确的答案，结尾回扣开头；一个人人都有的日常体验，用一个硬核理论来回答，落在"这不是你没出息，是大脑的设计"。

第二版（现在的成片）按"画面不够精美，动效不够华丽"的反馈把画面层整个重做了，文案和节奏没动：

- **整屏出血 + 三种底**：纸、夜、群青之间用擦除、刀切或者镜头"扎"满来切换。
- **一个连续的推镜头**：烛光里写字的人 → 扎进桌上那张纸（它就是下一屏整页原文的缩小版）→ 扎进"белого медведя"两个词之间的缝 → 整屏群青，一只巨大的白熊在雪里走。
- **每一段一个大动作**：94 只白熊飞回去拼成一只大白熊；时间尺 124 年一口气飞过去；5 分钟压成 5.5 秒的 300 格；盖子被顶飞、白熊涌满管子；272 只白熊铺满整个脑子再翻成别的念头；白熊像屏保一样来回弹；红色小汽车开过去把白熊换掉；结尾白熊站起来自己走掉，只剩空格子。
- **一个信号色**：群青 `#1F3FFF`，只给那只白熊——一块群青方块，白熊镂空在里面。唯一的第二种颜色是"替身"那辆红色小汽车。只有白熊（和替它的小汽车）做匀速直线运动，其他一切都吸附在拍子上。
- **光**：夜里的东西只在光里看得见（烛光、月光、路灯、冰箱灯、手电）。
- **网格有含义**：实验那一幕，1 行 = 1 分钟，1 格 = 1 秒，铃响的那一秒弹出一只白熊。
- **声音**：白熊每出现一次，就是一声桌铃（实验里受试者每想到一次就按一下铃），越来越密时变成钟琴；镜头扎进去、东西飞过去是一声"呼"；时间尺每过十年"嗒"一下。钩子里是钟的滴答，片名时圆舞曲进来，原理那段换成心跳一样的底鼓和"检查"的滴答，129 秒强拍全部停下，只留最后一声铃。混音 −14 LUFS。

| 秒 | 段落 |
| --- | --- |
| 0–14 | 10 秒挑战：被刀切成条的倒计时，白熊越冒越多；时间到，94 只飞回去拼成一只大白熊："你刚才，想了几次？" |
| 14–18 | 片名：白熊效应——越不让想，越会想起 |
| 18–30 | 01 起源：1863 年，烛光里的陀思妥耶夫斯基；俄文原句，"白熊"被标成群青；雪里的巨熊；每分钟冒出一只 |
| 30–60 | 02 实验：1987 年韦格纳的白熊实验——独自 5 分钟、想到就按铃；铃声平均每分钟至少一次；接下来允许随便想时，先忍过的人想得更多（反弹效应） |
| 60–90 | 03 原理：1994 年的讽刺性加工理论——脑子里一个"找事的"、一个"检查的"；每检查一次，白熊就出现一次；人一累，只剩检查的那个，白熊铺满整个脑子 |
| 90–102 | 04 生活里：越想睡越睡不着、越想忘记一个人越记得清楚、越告诉自己别吃越想吃 |
| 102–120 | 05 办法（Wegner 1987 / 2011）：给白熊找个替身；别赶它走 |
| 120–132 | 尾声："现在，你可以想白熊了。"它自己走了。放过它，它才会走 |

文件：

- `src/wb/score.ts`：总谱（时间、文案、白熊出现的时刻、实验的铃声、手电检查的节奏、要和声音对上的画面时刻、拟音事件，以及唯一的缓动曲线）
- `src/wb/sys.ts`：色板、三种底、网格、两条曲线（时值按 60 BPM）、刀切
- `src/wb/film/`：`Kit`（换底、镜头、开缝、翻牌、刀切）、`Bear`（白熊剪影和群青方块）、`Hook`（倒计时、白熊乱冒、马赛克大白熊、片名）、`Origin`（烛光屋子、原文、雪里的巨熊、秒表）、`Lab`（时间尺、实验室、5 分钟格子、柱状图、反弹管）、`Mind`（弹簧、两个工人和手电、满脑子白熊）、`Life`（月光、路灯、冰箱灯、侧脸）、`Methods`（屏保、替身和小汽车、别赶它走、尾声、空格子）、`Furniture`、`Type`、`Film`

- `src/wb/TREATMENT.md`：创作方案
