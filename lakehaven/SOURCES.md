# Lakehaven 底图的来源与做法

## 地图本身

- Cities: Skylines II 自定义地图 **Lakehaven**，作者 CityLogic，Paradox Mods #162872（2026-10-11 发布，建议版本 1.6.*，需要 Bridges & Ports DLC）。
- 作者描述：灵感来自加拿大新不伦瑞克省圣约翰和五大湖区；3 个高速出口、2 个铁路出口；资源有肥沃土地、石油、矿石。

作者没有发布俯视图，地图文件需要登录 Paradox 账号才能下载，所以底图是从公开截图反推出来的：

## 做法

1. **透视校正**：每张截图按针孔相机模型投影回地面平面（视场角按 45° 估，俯仰角从地平线位置推算），得到俯视图。
2. **识别水面**：按颜色（蓝减绿）和纹理（森林纹理粗、水面平滑）区分水和陆地，再从已知的水面点往外扩，避免把森林阴影当成水。
3. **对齐**：以模组页全景图为基准，把另外两张图的水面形状和它比对，自动优化投影变换，让重叠区的水面尽量重合（吻合度：第 1 集画面 96%，第 3 集画面 90%）。
4. **描岸线**：三张图按分辨率择优合成一张水面图，用等值线提取岸线，再做简化和平滑，结果存进 `geometry.json`。
5. **手工补正**：双子桥下的小湖、悬索桥下和市中心大桥下的水面，在识别时被桥面切断，按照片手工补上了。道路、分区、地名都是手工放的。

## 精度和局限

- 地图中部（市中心到悬索桥）的相对位置大约准到 100–200 m，越往图边越差。
- 比例尺按市中心街区间距估算（1 单位约 3 km），误差约 ±20%。
- 方向是纸面约定（上方 = 大湖），游戏里没有指北针；进游戏后按大湖、堤道把纸转正。
- 21×21 网格只是纸面坐标，不对应游戏的地块。
- 南部、东部、东北角没有照片（图上画斜线），那里的地形和高速出口位置都是推测。
- 两条铁路在照片里看不清，没有画；资源分布也不知道，留了标注框。

## 修改

- 岸线：编辑 `geometry.json`（`water` 里每个环的 `edge` 为 1 的点是照片覆盖范围的边，不画岸线）。
- 道路、分区、标注：编辑 `build_map.py` 顶部的坐标表（单位同上）。
- 重新生成：`python3 lakehaven/build_map.py && node lakehaven/render_pdf.js`
