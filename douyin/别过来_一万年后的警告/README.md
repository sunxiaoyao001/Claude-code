## 下载哪个文件

| 文件 | 说明 |
|---|---|
| `别过来_V2_1080p_手机直接播放版.mp4` | 1080p 30 帧，体积小于 100MB，点开就能直接下载播放，适合手机快速查看 |
| `4K原片_分卷/` | **最高画质成片**：3840×2160、60 帧、H.264 High@5.2、AAC 320kbps。按 95MB 分卷，下载整个文件夹后合并即可 |

### 合并 4K 原片

1. 下载 `4K原片_分卷` 文件夹里的全部 `BGL_V2_4K60.mp4.partXX` 文件和合并脚本，放在同一个文件夹
2. Windows：双击 `合并_Windows.bat`；Mac：双击 `合并_Mac.command`（首次运行可能要在“系统设置 → 隐私与安全性”里允许）；Linux：`bash 合并_Linux.sh`
3. 得到 `别过来_V2_4K60.mp4`，可用 `SHA256SUMS.txt` 第一行的值校验

> 分卷是因为 GitHub 普通文件上限 100MB，而本次运行环境的网络策略拦截了 Git LFS（`lfs.github.com`）。

## V2 相比 V1 的升级

- **前 13 秒重做开头**：“5000 年 vs 10 万年”数字冲击 → 地下发光的核废料 → 0.6 秒一切的高光快剪 → 片名“别过来”砸下；静音也能看懂
- **15 秒内交代看点**：“带你看看人类为了这一句警告，想出了多少疯狂的办法”
- **中段钩子**：“而最疯狂的，来自建筑师”“开头那句话，就出自这里”前后呼应
- **结尾互动**：“如果让你给一万年后的人留一句话，你会写什么？评论区告诉我”
- **节奏**：语速提到约 4.9 字/秒，转场从 0.9 秒缩到 0.45 秒，章节卡缩短，总时长从 10:08 压到 9:40
- **画面**：关键词和数字在字幕里金色高亮；每句旁白开始时画面轻推一下；时间轴镜头跟随事件推进；警告信段落加入双层旋转文字环和分句背景元素；建筑方案段改为闪白硬切
- **声音**：开头段落加入数字滚动声、盖革计数器、心跳和快剪冲击；每个转场有过渡音效
- **封面**：加入“文字只有 5000 年 / 它却危险 100000 年”的反差数字

V1 版本保留在 git 历史里（提交 `724abec`）。
