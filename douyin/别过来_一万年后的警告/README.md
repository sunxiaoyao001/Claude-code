## 下载哪个文件

| 文件 | 说明 |
|---|---|
| `别过来_1080p_手机直接播放版.mp4` | 1080p 30 帧，体积小于 100MB，点开就能直接下载播放，适合手机快速查看 |
| `4K原片_分卷/` | **最高画质成片**：3840×2160、60 帧、H.264 High@5.2、AAC 320kbps、约 1.2GB。按 95MB 分成 13 卷，下载整个文件夹后合并即可 |

### 合并 4K 原片

1. 下载 `4K原片_分卷` 文件夹里的全部 13 个 `BGL_4K60.mp4.partXX` 文件和合并脚本，放在同一个文件夹
2. Windows：双击 `合并_Windows.bat`；Mac：双击 `合并_Mac.command`（首次运行可能要在“系统设置 → 隐私与安全性”里允许）；Linux：`bash 合并_Linux.sh`
3. 得到 `别过来_4K60.mp4`，可用 `SHA256SUMS.txt` 里第一行的值校验

> 分卷是因为 GitHub 普通文件上限 100MB，而本次运行环境的网络策略拦截了 Git LFS（`lfs.github.com`），无法直接上传单个大文件。
