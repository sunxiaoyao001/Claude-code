# 方圆

四个形状的平台跳跃冒险。纯 HTML5 Canvas + 原生 JavaScript，没有任何依赖和美术素材，所有图形和声音都由代码实时生成。

## 怎么玩

用浏览器打开 `index.html` 即可（双击本地文件也能玩）。手机、平板会自动显示触屏按键。

| 操作 | 键盘 | 手柄 |
| --- | --- | --- |
| 移动 | ← → / A D | 摇杆 / 十字键 |
| 跳跃（按住跳更高） | 空格 / Z / ↑ / W | A |
| 空中下砸 | ↓ / S | 下 |
| 从薄平台落下 | ↓ + 跳跃 | 下 + A |
| 冲刺（尖尖、星星） | Shift / X | B |
| 暂停 | Esc / P | Start |

## 内容

- **4 个世界、16 个关卡**：晨光草地、落日峡谷、霜白高原、星夜之巅，每个世界 3 个关卡加 1 场首领战。
- **4 位首领**：方块大王（跳跃冲击波）、烈日（火雨与滚动冲撞）、霜棱（冰锥雨与俯冲）、星蚀（三阶段弹幕、激光与召唤）。
- **5 个角色**，各有能力：小方（二段跳）、阿圆（滑翔、跑得快）、尖尖（冲刺，能撞碎砖块和带刺敌人）、小菱（蹬墙跳）、星星（二段跳 + 冲刺，通关后加入）。
- **局外成长**：金币商店里有生命上限、金币磁铁、泡泡护盾、招财、保险五种永久升级。
- **收集**：每个普通关卡藏着 3 颗宝石，用来解锁角色；记录界面保存最佳时间与各项统计。
- **机关与敌人**：弹簧、移动平台、崩塌块、裂纹砖、冰面、强风、星光球；走走、刺刺、跳跳、飞飞、炮台、蝙蝠、压石、锯片、冰锥。
- 自动存档（localStorage），可在设置里调节音乐、音效、震屏、计时与触屏按键。

## 目录

```
index.html          页面入口
style.css           菜单界面样式
js/util.js          数学、颜色、本地存储
js/input.js         键盘 / 手柄 / 触屏输入
js/audio.js         WebAudio 合成音效与程序化音乐
js/data.js          物理参数、角色、升级、存档
js/levels.js        世界与关卡地图（字符画）
js/tilemap.js       瓦片地图与关卡解析
js/draw.js          形状、角色、背景、瓦片绘制
js/player.js        玩家手感与能力
js/entities.js      物件、敌人、粒子
js/bosses.js        四位首领
js/level.js         单局游戏：相机、碰撞、HUD
js/ui.js            菜单界面
js/main.js          主循环与流程
tools/check-levels.js  关卡可达性检查
```

## 关卡检查

`levels.js` 里的地图用字符画编写（图例见文件开头）。改完地图后运行：

```
node tools/check-levels.js          # 检查全部关卡
node tools/check-levels.js 2-3      # 只检查某一关
```

它会用游戏里的物理参数模拟各种跳跃，确认终点、检查点和全部宝石都能只靠基础动作（跑、跳、下砸）拿到，并报告缺少折返标记的平台和锯片。
