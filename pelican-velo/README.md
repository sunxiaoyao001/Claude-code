# 鹈鹕骑行 · Pelican Velo

一只戴头盔、围红围巾的大白鹈鹕，在海边公路上骑公路车。单个 HTML 文件，用 Three.js 实时渲染，模型、贴图和音效全部由代码生成，没有用到任何外部素材。

直接用浏览器打开 `index.html` 即可（需要联网加载 three.js 和字体）。

## 能做什么

- **鹈鹕**：腿和翅膀用两骨骼 IK 实时解算，脚踩踏板、翅膀握车把；脖子是每帧重建的 S 形锥管；身体随踏频起伏，头部保持稳定（鸟类的头部稳定反射）；会眨眼，喉囊会晃，吞鱼后会鼓起；围巾是实时变形的飘带。
- **自行车**：辐条、牙盘、8 速飞轮、链条、后拨都是程序建模；链条贴图随踏频滚动，换挡时链条会在飞轮上横移；高速时辐条出现运动模糊。
- **场景**：自定义着色器的海浪（菲涅耳反射、太阳高光、岸边白沫）、渐变天空（太阳、月亮、星星）、棕榈树、灯塔（夜间旋转光束）、帆船、海鸥、路灯、草地和贝壳（InstancedMesh）。路面、沙滩和道具循环滚动，形成无尽的路。
- **日夜**：拖动时间滑块，或开启“日夜流转”；天空、雾、海面、光照、路灯、车灯、尾灯一起变化。
- **接鱼小游戏**：鱼会从海里跃起，飞过公路，按空格张嘴接住。
- **镜头**：自由 / 追随 / 侧拍 / 鹈鹕视角 / 电影（自动切镜）。
- **声音**（Web Audio 合成）：海浪、风声、胎噪、车铃、拍喙声、吞咽声、水花、换挡声、海鸥叫。
- **码表**：速度、踏频、齿比、里程、接到的鱼、海岸时间、鹈鹕心率。

## 按键

| 按键 | 作用 |
| --- | --- |
| ↑ / W，↓ / S | 加速 / 刹车 |
| 空格 | 张嘴接鱼 |
| F | 振翅（会借到一点风，还能离地一下） |
| B | 按铃 |
| Q / E | 换轻挡 / 换重挡（会切换为手动变速） |
| C | 切换镜头 |
| T | 时间 +1 小时 |
| M | 声音开关 |
| N | 观察笔记 |
| H | 隐藏界面 |

点击鹈鹕，它会转头看你并拍喙；点击自行车会按铃。
