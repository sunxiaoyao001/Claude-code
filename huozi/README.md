# 活字背单词

用活字印刷的方式背单词：单词被拆成词根、词首、词尾三类“字模”，你按字面线索把它们排进手托、按下印刷。记忆的好坏用油墨的浓淡表示。

纯静态网页，无需构建。直接用浏览器打开 `index.html`，或者在仓库根目录运行 `npx serve huozi`。

## 三个页面

- **排字**：每天的学习和复习。
  - 新词只给中文释义和字面线索（比如「向里面看」），由你推理出 `in- + spect`。
  - 复习时换成例句填空，字模上不再标意思，还会混进同义的干扰字模（比如 `in-` 和 `im-` 都是“向内”），考的是词形。
  - 排错的字模会被打上校对红线。系统根据失误次数自动评分，不用自己按“记得 / 忘了”。
- **字盘**：把 163 块字模全部摆出来，可以随意拼词。拼出词库里的词，它就直接印进校样，并标上 †。另有“拆一个生词”：输入任何英文单词，按已知字模拆开，给出字面猜测。
- **校样**：170 个词按 30 个词根排成一张字体样张。学过的词着墨，墨色就是当前记忆的强度；没学的词只是纸上的凹痕。拖动时间滑块，可以预览不复习的话几天后会忘掉哪些词。

## 记忆模型

可提取率 `R = 1 / (1 + t / 9S)`，其中 t 是距上次排字的天数，S 是稳定度（单位：天）。R 降到 90% 时，这个词就该重印了。每次重印后 S 增长；越接近遗忘时复习、排得越顺，S 涨得越多。

## 文件

| 文件 | 内容 |
| --- | --- |
| `data.js` | 词库：字模表和 30 个词根族（每个词含音标、释义、拆分、字面意思、例句） |
| `app.js` | 交互、记忆模型、存储（浏览器 localStorage；在 Claude 页面里打开时额外存到账号） |
| `styles.css` | 单色凸版印刷风格。深色模式是蓝晒效果 |

扩充词库时，每个词的字模拼起来必须和单词完全一致；拆分时同形异义的字模用 `~` 区分（如 `in` 向内、`in~` 不）。
