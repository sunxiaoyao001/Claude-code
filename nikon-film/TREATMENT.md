# 百年，为看见 — 尼康品牌短片 · 分镜与节拍表

**格式**：16:9 · 1920×1080 · 24 fps · 90.0 s · 只有音乐与字卡
**节拍网格**：96 BPM，4/4。1 拍 = 0.625 s = **15 帧整**（24 fps 下每个拍点都落在整帧上）。1 小节 = 2.5 s。全片 36 小节 = 144 拍。
**结构**：B（百年时间线）为主干，C（组装）作为贯穿全片的角标，A（焦段）作为第 5 章的快切段落。
**双语**：中文永远是大标题；第二行由开关 `SECOND=en|zh` 决定（英文译名 / 中文说明），不手改卡片。
**品牌**：不复刻尼康官方标志与官方口号。"尼康 / NIKON"用片中字体排版，口号"百年，为看见"为本片原创。相机、镜头一律画成几何象形图。

## 4. 声音

- **鼓组为脊**：太鼓式低鼓（1、3 拍）+ 边击（2、4 拍）+ 沙锤十六分 + 第 2 章起加拍手；章节卡起镲。
- **色彩乐器**：合成贝斯八分音、失谐锯齿和弦短促重音（第 4、5 章反拍）、木琴琶音（第 1、3 章）、Karplus-Strong 拨弦动机（片头与结尾）、铺底 pad、上升音效两次、片头低鸣。
- **按章节的音效**：玻璃铃 → 机械快门（反光镜拍击 + 快门）→ 对焦"嘀嘀" → 电子快门 → 呼啸 + 快门。每个镜头起点一个，由剪辑表数据定位，逐个检查到 ±15 ms。
- **静默**：b68–72 整小节只剩滴答，压在计数下面；b119.5–120 半拍全静。
- **混音**：总线胶水压缩 + 限幅，−14 LUFS；WAV 真峰值压到 −2 dBTP，留出 AAC 编码余量，保证成片 ≤ −1 dBTP。
