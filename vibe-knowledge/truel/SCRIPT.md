| 项目 | 内容 |

| 核心反差 | 枪法最差（40%）的丙，最后活下来的概率最高（50.1%）；枪法最好（80%）的甲最低（19.0%） |

## 二、规则与数学（视频里所有数字都由 `src/math/truel.ts` 算出）

- 甲 80%，乙 60%，丙 40%；轮流开枪，顺序丙 → 乙 → 甲 → 丙……，死者跳过；每次一枪，目标自选，打到只剩一人为止。
- 甲和乙互为最大威胁，只要三人都还活着，他们一定先互相开枪。

| 情形 | 丙的存活率 |
|---|---|
| 丙打中甲后（乙先手单挑丙） | 21.05% |
| 丙打中乙后（甲先手单挑丙） | 9.09% |
| 开局一直打甲 | 37.92% |
| 开局一直打乙 | 32.89% |
| **开局朝天开枪** | **50.14%** |

朝天开枪时三人的最终存活率（理论值）：**丙 50.1%　乙 30.9%　甲 19.0%**

蒙特卡洛模拟 10000 场（固定种子 20261052）：丙 5015 场　乙 3083 场　甲 1902 场

校验命令：`npm run math`
