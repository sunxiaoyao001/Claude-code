## 二、事实与数字

### 有出处的部分

- **游戏规则与理性解**：每人从 0～100 中选一个数，最接近“全体平均数 × 2/3”的人获胜。反复剔除被占优的选择，唯一的纳什均衡是所有人都选 0。
- **纳格尔的实验**：Rosemarie Nagel (1995), “Unraveling in Guessing Games: An Experimental Study”, *American Economic Review* 85(5): 1313–1326。每组 15～18 人，p = 2/3 的第一轮：67 个选择，平均 36.7，中位数 33，没有人选 0；选择集中在 50 × (2/3)^k 附近，即 33（第 1 层）和 22（第 2 层）。多轮重复后数字会逐渐向 0 靠拢。
- **《金融时报》读者大赛（1997）**：Richard Thaler 主持。平均数 18.91，2/3 约为 12.6，赢家选 13（也有资料按不同的计数口径记为 12）。
- **丹麦《政治报》（Politiken，2005）**：19,196 人参加，奖金 5000 丹麦克朗，正确答案（平均数的 2/3）是 21.6，对应平均约 32。另有资料写“平均约 22、答案 14”，与多数来源不符，未采用。
- **层级思考模型**：Camerer, Ho & Chong (2004), “A Cognitive Hierarchy Model of Games”, *Quarterly Journal of Economics* 119(3): 861–898。各层人数用泊松分布描述，跨许多博弈拟合得到的平均思考层数 τ ≈ 1.5。
- **凯恩斯的选美比赛**：Keynes (1936)《就业、利息和货币通论》第 12 章：报纸刊出 100 张照片，读者选出最美的 6 张，选择最接近全体读者平均偏好的人获奖。他写道：我们已经到了第三层——用智慧去预测“一般人认为一般人会怎么想”，有人还会做到第四、第五层乃至更高。他用这个比喻说明专业投资。

### 示意图（画面上已标注“示意”）

| 画面 | 依据 |
|---|---|
| 纳格尔实验的点状直方图（67 个点） | 按论文的统计量构造：67 个数、平均 36.69、中位数 33、没有 0，33～34 有 10 人，21～23 有 7 人。`npm run math` 校验 |
| 100 个人的层级分布 | τ = 1.5 的泊松分布四舍五入：第 0～4 层 22 / 33 / 25 / 13 / 5，5 层以上 2，合计 100 |
| 股价泡沫曲线 | 只表达“上涨 → 破裂”的形状，没有对应真实数据 |

### 视频里自己算出来的数字（`npm run math` 可复现）

| 数字 | 计算 |
|---|---|
| 规则举例：10、30、50、70、90 | 平均 50 → × 2/3 = 33.3 → 最接近的是 30 |
| 层级推理：50 → 33 → 22 → 15 → 10 → 7 → 4.4 → 2.9 → … → 0 | 第 k 层选 50 × (2/3)^k |
| 全员选 0 是纳什均衡 | 其他人都选 0 时，单独改选任何 x > 0 都会比 0 离目标更远（脚本逐个验证 1～100） |
| 改选 5 的例子 | 五个人里一人改选 5：平均 1，× 2/3 ≈ 0.67，他离目标 4.33，其他人只差 0.67 |
